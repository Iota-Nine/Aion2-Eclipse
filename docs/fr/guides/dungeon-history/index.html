Historique et analyse des runs

Un run AION 2 enregistré permet de revoir le combat après avoir quitté le donjon. Eclipse relie l’historique local à l’analyse du groupe pour examiner les dégâts de chaque personnage au-delà d’un seul chiffre DPS.

Ouvrir un run depuis l’historique

Sélectionnez un run terminé ou interrompu dans l’historique pour ouvrir son analyse de groupe. Consultez les dégâts totaux de chaque joueur, les barres de dégâts, les compétences, les critiques et la chronologie. Revenez ensuite à l’historique pour choisir un autre run.

Les notes et favoris aident à conserver les combats utiles. Les archives sont enregistrées sur votre PC ; aucun compte du site n’est nécessaire pour les consulter.

Conserver les totaux du donjon

Les TP internes conservent le run en cours. Les morts reconnues des boss finaux archivent les donjons pris en charge ; les autres fins restent manuelles. Une sortie avant la fin peut être gardée comme run interrompu.

La version 3.0.15 conserve aussi le run quand un identifiant local est réattribué avant les informations de résurrection. Alt+R garde volontairement le run actuel comme interrompu avant de repartir sur un nouveau compteur.

Comparer vos propres builds

Enregistrez vos presets de build et comparez vos résultats. Privilégiez des combats avec une cible, une durée et des conditions de groupe similaires pour rendre la comparaison utile.

Un changement de dégâts peut venir du combat ou du groupe autant que du build. Eclipse utilise vos archives personnelles ; ces comparaisons ne sont pas un classement méta mondial en direct.

Donner du contexte au soutien

Regardez les soins reçus et les observations de boucliers ou buffs disponibles à côté des dégâts. La contribution du soutien mérite du contexte ; les mesures inconnues restent inconnues plutôt que d’être estimées.

LES GUIDES ECLIPSE

Prenez Eclipse en main.

Installation, raccourcis et résultats de combat : des guides pratiques pour votre prochain run AION 2.

01

Installer Eclipse

Installez Eclipse sur Windows 10 ou 11, configurez Npcap si nécessaire et découvrez vos premiers dégâts AION 2 ainsi que les raccourcis de l’overlay.

02

Overlay DPS et raccourcis

Affichez le DPS du groupe, les dégâts du personnage et le soutien dans l’overlay compact AION 2. Découvrez Alt+F8 et les commandes du HUD Eclipse.

03

Timers de boss et alertes

Suivez les boss AION 2, les failles et vos favoris dans Eclipse. Activez les rappels à 10 minutes, 5 minutes ou à l’heure prévue et arrêtez-les avec Alt+M.

04

Soins et soutien

Comprenez les statistiques AION 2 d’Eclipse : soins reçus, utilisations de boucliers et buffs sélectionnés du Cleric et de l’aède, à côté des dégâts du groupe.

05

Historique et analyse des runs

Analysez vos donjons AION 2 avec Eclipse : dégâts totaux par joueur, compétences, critiques et soutien, historique local et comparaisons personnelles de builds.
