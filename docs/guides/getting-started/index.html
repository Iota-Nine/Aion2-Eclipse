Install Eclipse

Download and install

Use Eclipse-Setup.exe from the official GitHub release. The application is included in the setup. Eclipse supports 64-bit Windows 10 and Windows 11, with English as the initial language and French available in Preferences.

  1. Download the installer using the button on this page.
  2. Follow the setup. If Npcap is needed, complete its official installer and approve the requested Windows permission.
  3. Open Eclipse, then enter AION 2. Keep Eclipse running while you play.

Your first combat

The HUD starts enabled. Use Alt+F8 to show or hide it. Received game-network events populate the meter when combat is detected; an empty meter before combat is expected.

If numbers stay empty during a fight, check the capture status in the client. Missing events cannot be reconstructed from a screenshot. Use Report a bug with your Eclipse version and the steps that caused the problem.

Make it comfortable

Ctrl+Alt+L locks or unlocks mouse interaction with the HUD. Move the overlay to a comfortable position, switch between compact and full layouts, or leave the full client on another screen.

No website account is required for combat tools or local history. Accounts are for private suggestions and replies. Eclipse is free, without a subscription.

Keep Eclipse up to date

UPDATE appears in the client when a newer release is detected. The official download button also points to the latest installer. Updates preserve local preferences and run history; the ZIP is available on GitHub for players who prefer it.
