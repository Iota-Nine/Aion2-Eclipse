GOOD TO KNOW

Before your first run

How is DPS calculated?+

Eclipse reads received combat events. DPS is accumulated damage divided by the measured fight duration; burst uses a shorter window. The average does not reset every second.

Does it work in every region?+

Timers support six services. Damage capture also depends on the game protocol, traffic and Npcap. Unknown values stay unknown; server or game updates can require an Eclipse update.

Are timers live spawn detections?+

No. These are bundled AION2Hub schedules checked on 3 October 2026. Global and KR use UTC+9; TW uses UTC+8. Travel portal duration is not confirmed by that source.

When do totals reset?+

Recognised local teleport/player-info events archive the previous run and reset totals, including some non-dungeon teleports. Manual reset is available; exact dungeon names are not guaranteed.

What does the site collect?+

Only information you explicitly submit in the bug form is stored. Combat archives and client settings remain on your PC. Reports are not publicly accessible.
