# Eclipse

Free AION 2 DPS meter for Windows x64.

[Download latest](https://github.com/Iota-Nine/Aion2-Eclipse/releases/latest) — take the `.zip`, not Source code.

## Install

1. Download the zip
2. Extract the whole folder to a writable location, such as Documents
3. Install [Npcap](https://npcap.com/#download) (WinPcap API-compatible mode)
4. Run `Aion2-Eclipse.exe` before entering the world; if already in-game, teleport once

## Features

- Live party DPS overlay
- Player levels in the party list
- Click-through HUD
- Auto-update with download integrity checks

## Controls

| Action | Key |
|---|---|
| Hide / show | `Ctrl+Shift+H` |
| Click-through | `Ctrl+Shift+L` |
| Reset | `Ctrl+Shift+R` |

## Notes

Windows 11 x64 recommended. The .NET runtime is included; Npcap is installed separately.

There is no country or Windows language restriction. Compatibility depends on the AION 2 client protocol; not all game regions and PC configurations have been tested.
