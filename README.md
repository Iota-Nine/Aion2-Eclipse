# Eclipse

Free AION 2 DPS meter for Windows x64.

[Download latest](https://github.com/Iota-Nine/Aion2-Eclipse/releases/latest) — take the `.zip`, not Source code.

## Install

1. Download the zip
2. Extract the whole folder to a writable location, such as Documents
3. Run **`Eclipse.Setup.exe`**
4. Accept Windows permission and complete the Npcap installer if prompted. Eclipse opens when setup finishes.

Setup installs Eclipse in your user account and creates Desktop and Start menu shortcuts. The .NET runtime is included. If [Npcap](https://npcap.com/#download) is missing, setup downloads and opens its official installer automatically; Internet is needed for that step.

Start Eclipse before entering the world; if already in-game, teleport once. Join your party after starting Eclipse so its member information can be received.

## Features

- Live party DPS overlay
- Player levels in the party list
- Click-through HUD
- Auto-update with download integrity checks
- Integrated setup with automatic prerequisite detection

## Controls

| Action | Key |
|---|---|
| Hide / show | `Ctrl+Shift+H` |
| Click-through | `Ctrl+Shift+L` |
| Reset | `Ctrl+Shift+R` |

## Notes

Windows 11 x64 recommended. Existing portable installations continue working; the first launch also offers prerequisite setup when necessary.

There is no country or Windows language restriction. Compatibility depends on the AION 2 client protocol; not all game regions and PC configurations have been tested.
